# قطاع الخادم المركزي (Backend Service - Laravel)

يمثل هذا المجلد الخادم المركزي لنظام **فارما-كونكت (PharmaConnect)** وفق معمارية خادم وعميل الموزعة.

## المسؤوليات التقنية:
1. **بوابة ويب لإدارة مخزون الصيدليات (Multi-Tenant Inventory Web Portal):**
   - تمكين كل صيدلية مسجلة من إدارة مخزونها، تحديد كميات الأدوية، والأسعار، واستقبال طلبات الحجز.
2. **واجهات برمجة التطبيقات الموحدة (Centralized RESTful APIs):**
   - تقديم نقاط نهاية سريعة وآمنة ومحمية بـ (Laravel Sanctum) لخدمة تطبيق الهاتف (Flutter).
3. **منطق الحجز الآني والتحكم بالتزامن (Concurrency & TTL Logic):**
   - إدارة حجز الأدوية المؤقت ومنع التعارض عند طلب نفس الصنف في نفس التوقيت.

## متطلبات التشغيل:
- PHP 8.2+
- Composer 2.x
- MySQL 8.0+
- Redis (اختياري للتخزين المؤقت المتقدم)

## فحص الكود والاختبارات:
- **فحص التنسيق بـ Laravel Pint:**
  ```bash
  ./vendor/bin/pint --test
  ```
- **تشغيل الاختبارات التلقائية:**
  ```bash
  php artisan test
  ```
