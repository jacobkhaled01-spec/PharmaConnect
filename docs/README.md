# وثائق وهندسة نظام فارما-كونكت (PharmaConnect Architecture & Docs)

يحتوي هذا المجلد على كافة الوثائق الرسمية والتصاميم المعمارية للنظام الموثقة بنظام **APA 7th Edition**.

## محتويات المجلد:
1. **مواصفات متطلبات النظام (Software Requirements Specification - SRS):**
   - المتطلبات الوظيفية وغير الوظيفية وقصص المستخدم ومعايير القبول.
2. **مخططات النمذجة الموحدة (UML Diagrams):**
   - مخططات حالات الاستخدام (Use Case Diagrams).
   - مخططات الفئات والواجهات (Class Diagrams).
   - مخططات التتابع (Sequence Diagrams).
   - مخططات الأنشطة (Activity Diagrams).
3. **تصميم قاعدة البيانات (Database Schema & ERD):**
   - مخطط الكيانات والعلاقات والتطبيع (3NF).
4. **توثيق واجهات الـ APIs:**
   - توثيق تفصيلي لنقاط الاتصال، معايير التحقق، وأكواد الاستجابة.
