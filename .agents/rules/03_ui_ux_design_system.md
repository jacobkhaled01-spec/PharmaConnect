# نظام تصميم وهوية واجهات المستخدم (Medical UI/UX Design System)

تحدد هذه القاعدة الإطار البصري والهندسي الموحد لكافة واجهات المستخدم (Web Portal للصيدليات، و Flutter Mobile App للمرضى)، بالاعتماد على الهوية الطبية الراقية باللونين الأخضر النقي والأبيض الصافي مع أعلى معايير الـ UX.

## 1. لوحة الألوان المعتمدة (Medical Color Palette)

```css
:root {
  /* درجات الأخضر الطبي الأساسية (Primary Emerald Greens) */
  --color-primary-900: #064E3B; /* أخضر غامق جداً للعناوين والتأكيدات */
  --color-primary-800: #065F46;
  --color-primary-700: #047857;
  --color-primary-600: #059669; /* الأخضر الطبي الرئيسي */
  --color-primary-500: #10B981; /* الأخضر الحيوي للأزرار النشطة */
  --color-primary-100: #D1FAE5; /* نعناعي خفيف للبطاقات والحالات الإيجابية */
  --color-primary-50:  #ECFDF5; /* خلفية ناعمة جداً للتحديدات */

  /* درجات الأبيض والأسطح الصافية (Crisp Clean Whites & Grays) */
  --color-surface-white: #FFFFFF; /* الأبيض النقي للبطاقات والأسطح الرئيسية */
  --color-surface-bg:    #F8FAFC; /* خلفية التطبيق العامة المريحة للعين */
  --color-surface-border:#E2E8F0; /* حدود ناعمة وبسيطة */

  /* نصوص متباينة ومريحة للقراءة (Typography Grayscale) */
  --color-text-main:    #0F172A; /* كحلي فحمي داكن للنصوص الأساسية */
  --color-text-muted:   #64748B; /* رمادي متزن للنصوص التوضيحية */

  --color-status-low-stock: #D97706; /* وشيك النفاذ */
```

## 2. معايير تجربة المستخدم (User Experience - UX)
1. **قاعدة الـ 3 نقرات (3-Click Rule):**
   - يجب أن يصل المريض إلى نتيجة البحث عن الدواء أو الصيدلية وحجزها في 3 نقرات أو أقل من لحظة فتح التطبيق.
2. **التغذية البصرية الراجعة اللحظية (Immediate Visual Feedback):**
   - مؤشرات تحميل هيكلية ناعمة (Skeleton Loading) أثناء جلب البيانات بدلاً من الشاشات البيضاء الفارغة أو الدوائر المزعجة.
   - رسائل إشعار عائمة (Toasts / Snackbars) واضحة تؤكد نجاح عمليات الحجز أو التعديل.
3. **تصميم حالات عدم التوفر (Empty & Zero States):**
   - عند البحث عن دواء غير متوفر، يتم عرض بدائل علمية (Same Active Ingredient) واقتراح إرسال تنبيه فور توفره في أقرب صيدلية.
4. **معايير الوصولية والراحة البصرية (Accessibility & WCAG 2.1 AA):**
   - تباين كافٍ لا يقل عن 4.5:1 بين النصوص والخلفيات الخضراء والبيضاء.
   - خطوط طبية واضحة ومقروءة تدعم اللغة العربية والإنجليزية ببراعة (مثل Tajawal أو Cairo أو Inter).

## 3. معايير واجهات المستخدم (User Interface - UI Aesthetics)
1. **البطاقات والظلال الناعمة (Clean Soft Cards):**
   - حواف مستديرة ناعمة (`border-radius: 12px` إلى `16px`).
   - ظلال خفيفة وواقعية (`box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.05)`).
2. **التفاعلية والحركات الدقيقة (Micro-interactions):**
   - تأثيرات ناعمة عند التمرير والضغط (`transition: all 0.2s ease-in-out`).
   - شارات حالة المخزون الملونة (Badges: متوفر، متبقي 2 علبة، محجوز).
3. **التجاوب الكامل (Responsive Design):**
   - تصميم متكيف بنسبة 100% مع شاشات الهواتف بجميع أحجامها، ومع شاشات المتصفحات لأجهزة الصيدليات.
